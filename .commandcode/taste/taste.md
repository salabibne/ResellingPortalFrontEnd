# Taste

## UI / Styling
- Prefers dark-themed admin navigation: wants the admin panel's left sidebar to use a black background with white text/icons. Confidence: 0.5
- Wants admin navigation to live in the vertical left sidebar as collapsible groups placed directly under Dashboard; considers horizontal tab/nav bars for admin sections non-standard. Confidence: 0.6
- Expects new nav structures to mirror the existing pattern already in the sidebar (e.g. the "Products & Attributes" group) rather than inventing a new layout. Confidence: 0.55

## Tooling / Deployment
- Deploys the Next.js frontend to Render as a web service. Confidence: 0.6

## Communication
- Debugs by pasting the full raw build/deploy log and asking a short, low-context question; wants the root cause diagnosed and explained in plain language before fixes are applied. Confidence: 0.5
